🔍 AI Transparency & Tracing
Observability

Every local LLM call is measured and logged so analysts can verify how an AI answer was produced — never a black box.

1
Wrap Every AI Call (AITraceContext) Automatically instruments Triage summaries, Chat Q&A, and multi-step SOC Agent tool turns.
2
Track Cost, Speed & Actions Records model name, latency (duration_ms), prompt/completion tokens, and tools invoked.
3
Capture Full Failure Tracebacks If Ollama fails or times out, full stack traces are saved to MongoDB for instant root-cause debugging.

🐬 Flipper Zero / NFC Badge Login
Physical Auth

Passwordless 1-tap analyst login using an RFID/NFC badge or Flipper Zero key, backed by an immutable audit trail.

1
Tap Badge or Flipper Zero Login screen features a dedicated Flipper Zero / NFC tab (auto-focus scanner + 1-click Demo Tap).
2
Verify UID & Issue Session (/auth/badge-login) Normalizes and matches the badge UID (FLIPPER-SOC-7A39B1) to issue a session token.
3
Commit to Cryptographic Ledger Writes BADGE_TAP_LOGIN into the SHA-256 hash-chained decision_ledger.

→ 200 OK Session Token → Ledger: PHYSICAL_AUTHENTICATION / BADGE_TAP_LOGIN
