Security

Protects every SOC endpoint with session tokens while capturing real sandboxed browser screenshots for phishing alerts.

1
Session Token & Ingest Key Protection All dashboard APIs require active Bearer session tokens; sensors use optional INGEST_API_KEYS.
2

3
Concurrency Cap & Demo Hardening Limits concurrent /verify browser checks to prevent overload + one-command setup_demo_hosts.py.
